## 我在做什么

我开发了一套**山区流域变暖响应快速筛查框架**，用于批量评估流域对气候变暖的敏感性，识别临近状态跃迁（“换锚”）的高风险流域。

传统水文研究回答“水从哪里来”（水源解析）。我的框架回答一个不同的问题：**当气候变暖，这个流域的季节径流结构会怎么变？会不会发生状态跃迁？**

### 核心指标

| 指标 | 定义 | 回答的问题 |
|---|---|---|
| **SRF**（春季径流占比） | 4-6月径流占全年径流的比例 | 流域依赖春季融雪的时间窗口有多长？ |
| **SEI**（季节性极端化指数） | 7-9月径流均值 ÷ 全年径流中位数 | 枯水期相对全年是在变干还是变湿？ |
| **锚定类型** | 积雪锚 / 混合锚 / 雨锚 / 隐锚 | 流域靠什么“记住”冬天的水？ |

> **重要说明**：SRF 是**季节结构指标**，衡量“径流什么时候发生”，不是**水源组分指标**（如积雪融水贡献占比）。两者回答不同问题，本框架不替代传统水源解析方法，而是提供互补的**筛查视角**。

### 框架来源

四锚分类源自一个更广泛的锚定框架，最初在星系尺度上开发和验证（Ou, 2024, DOI: 10.5281/zenodo.22714393）。本框架将该概念应用于水文系统，并已在**78个美国西部流域**和**14,406个中国山区格点**上验证。

## 案例演示

### 案例1：阿尔泰山西段子流域（高敏感）

- **位置**：86.0–87.5°E, 47.0–48.2°N
- **SRF**：0.384（混合锚下界）
- **SEI 趋势**：-0.0092/年（58年累计 -37.6%）
- **雪深趋势**：-0.058 厘米/年
- **融雪峰趋势**：-5.64 月/100年
- **结论**：三重信号一致，快速滑向雨锚

### 案例2：呼图壁河（天山北坡，低敏感）

- **位置**：86.05–87.08°E, 43.07–45.20°N
- **SRF**：0.377（混合锚下界）
- **SEI 趋势**：-0.0019/年（58年累计 -6.5%）
- **雪深趋势**：+0.009 厘米/年（基本稳定）
- **融雪峰趋势**：-0.50 月/100年
- **结论**：信号弱，冰川缓冲可能发挥作用

> **关键对比**：两个流域 SRF 几乎相同（0.384 vs 0.377），但系统敏感性截然不同。传统方法无法区分，本框架可以。
