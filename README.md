# Anchoring Framework｜锚定框架
> Cross-scale physical framework without invoking dark matter hypothesis
> 不依赖暗物质假说的跨尺度物理框架

## 📖 项目简介
本项目为《锚定框架：星系旋转曲线的零暗物质解释》配套仓库。
论文存档：https://doi.org/10.5281/zenodo.22713531
许可协议：CC BY-NC-ND 4.0（可阅读引用，禁止商用、禁止二次修改衍生）

本文提出一个不依赖暗物质假说的物理框架，用于解释星系旋转曲线的平坦化。该框架引入一个无量纲参数α，用于描述星系在密度下降时维持内部结构的能力。

在SPARC数据库98个高质量星系样本拟合：
- 中位残差：9.14 km/s
- 对比：MOND（11–13 km/s），NFW暗物质晕模型（14–17 km/s）
- α与星系气体质量占比显著负相关，$r^2=0.439$，$p<10^{-6}$
- 高气体星系α均值0.547；恒星主导星系α均值0.839

整套分析不引入暗物质参数，提供可观测检验的新动力学预言。
