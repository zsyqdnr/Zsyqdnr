## Core Idea
The Anchoring Framework treats all dissipative systems as wave-packets anchored to a background reference field.
Three fundamental variables govern the system behaviour:
- **S (Survival Factor)**: Persistence of the coherent structure
- **Gₐₙcₕₒᵣ (Anchoring Stiffness)**: Coupling strength between the structure and background field
- **R (Resonance Overlap)**: Spectral overlap between the structure and reference field

This set of variables works across vastly different scales: galaxies, watersheds, and neural oscillation cycles.

## Case Studies
### Case 1: Galaxy Rotation Curve Fitting
Traditional ΛCDM requires invisible dark matter to match observed rotation velocity.
The Anchoring Framework reproduces flat rotation curves purely from the background anchoring coupling, without introducing dark matter particles.

### Case 2: Gas-Stellar Disk Separation
Stellar components follow Newtonian gravity; gas components interact strongly with the background anchoring field.
This naturally explains the observed offset between stellar and gas rotation curves.

### Case 3: Yarlung Tsangpo Watershed
Mountain watershed as a dissipative anchored system.
Snow cover acts as a slow anchoring reservoir, shaping seasonal runoff response.

### Case 4: Hutubi River Watershed
Smaller alpine watershed with faster snow melt cycles.
> Key comparison: Two watersheds share nearly identical SRF scaling law despite huge differences in basin size and climate forcing.

### Case 5: Neural Limit-Cycle Crystallization (EEG)
At the microscopic neural scale, the same three variables map to EEG signals:
- SLC-C: Neural Limit-Cycle Crystallization degree
- Sync: Inter-channel phase synchronization
- Coverage: Spatial feature distribution percentile (reference cohort)

This is the implementation basis of **Taixu-Engine**.
